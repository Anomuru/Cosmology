# Космология Фантазии

Систематическое описание того, как устроено существование в мире Фантазии — от состояния до Циклов и до всего, что из него следует.

Это не каталог персонажей. Это описание механики: что есть, почему оно так работает, и какие законы из этого выводятся. Персонажи и Циклы опираются на этот слой, а не наоборот.

## Структура

| Файл | Что внутри |
|---|---|
| `00-beginning.md` | Начало. Двое без начала, первые творения, появление третьего, именование. Канонический текст событий. |
| `01-laws.md` | Законы, выведенные из начала. Нумерованные, с указанием, откуда следует каждый. |
| `02-trinity.md` | Реалист, Фантазёр, Существование — природа, способности, позиции, различия. |
| `03-divergence.md` | Расхождение: выбор Существования, первые расы, два способа быть богом. |
| `04-meaning.md` | Вопрос о смысле: Существование среди ангелов и демонов, Люцифер, Рафаэль, Асмодеус. |
| `05-meeting.md` | Встреча: первый разговор Реалиста и Фантазёра, диагноз и невозможность настоящего конца. |
| `06-beginning-and-end.md` | Начало и конец: собрание в Реальности, Азраил, Вариониэль, изображение в небе. |
| `99-open-questions.md` | То, что ещё не решено. Вопросы, на которые нужен ответ автора. |

## Пометки в тексте

- **[канон]** — заявлено автором, принято как есть.
- **[вывод]** — следствие, выведенное из канона, но автором пока явно не подтверждённое. Может быть отменено.
- **[?]** — открытый вопрос, см. `99-open-questions.md`.

`00-beginning.md` → `01-laws.md` → `02-trinity.md` → `03-divergence.md` → `04-meaning.md` → `05-meeting.md` → `06-beginning-and-end.md`. Законы без начала не читаются, начало без законов не объясняет ничего дальше.
